# FCO Airside Quiz 3.0

Android app for study support for FCO/CIA Airside Driving Certificate topics.

## Included banks
- ADC A / Apron: 111 questions
- ADC M / Area of Manoeuvre: 123 questions
- Total: 234 questions

## Features
- Separate ADC A and ADC M sections
- 20-question / 25-minute exam simulation for each bank
- 18/20 simulation threshold (study simulation only)
- Training, random questions and category practice
- Error review and category error statistics
- Italian / English / Spanish selector
- English/Spanish question translation through Google ML Kit on-device models
- Persistent language preference
- Dedicated study disclaimer
- Professional airplane app icon
- Gradle Wrapper included

## Build requirements
- Android Studio compatible with AGP 8.7.3
- JDK 17 for Gradle
- Internet connection for the first Gradle dependency sync
- Wi-Fi is recommended the first time English/Spanish translation models are downloaded

Do not upgrade Gradle/AGP/Kotlin automatically on first import. Use the included Gradle Wrapper.
